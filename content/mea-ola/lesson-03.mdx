## カヌー植物 — 人が運んだ層

**canoe plants**（カヌー植物）は、西洋との接触（1778年）より前にポリネシア人が双胴カヌーで持ち込んだ植物の総称です。Plant Pono（ハワイの外来種対策サイト）は「これら**23種**の植物がハワイ社会の繁栄を可能にした」とし、ハワイ州法（HRS 103D-408、2015年 Act 233）でも「1778年以前にポリネシア人が持ち込んだ植物」として定義されています。

| ハワイ語名 | 植物 | 主な用途 |
|---|---|---|
| <H>kalo</H> | タロイモ | 主食。蒸して潰し poi にする。人の「兄」 |
| <H>ʻulu</H> | パンノキ | 実は食用。乳液はカヌーの接着剤、材はカヌー・板・kiʻi |
| <H>niu</H> | ココヤシ | 食料・水・かご・屋根・綱。双胴カヌー1隻の綱に約11kmの繊維 |
| <H>kō</H> | サトウキビ | 薬を飲みやすくする。葉は屋根の内張り |
| <H>maiʻa</H> | バナナ | 食用と heiau への供物。多くの品種が女性に kapu。Kanaloa の kinolau |
| <H>wauke</H> | カジノキ | 内皮を叩いて最上級の kapa を作る |
| <H>ipu</H> | ヒョウタン | 容器。フラの打楽器 ipu heke に |
| <H>kī</H>（葉は <H>lāʻī</H>） | ティ | 供物を包む、雨具、hukilau 漁、pāʻū。Kāne の kinolau |
| <H>kukui</H> | ククイ | 実の油で灯明。炒った実は ʻinamona。油はカヌーのニス |
| <H>noni</H> | ノニ | 傷・骨折・筋肉痛の薬。根と皮から kapa の赤・黄の染料 |
| <H>ʻawa</H> | カヴァ | 儀礼の飲みもの |

<Photo id="loi-hanalei" caption="Hanalei（Kauaʻi）の loʻi kalo。水を張った田で kalo を育てる。国立野生生物保護区の中で農家が耕作を続けている。" />

<Note kind="unverified">
カヌー植物の種数は資料で揺れます。24〜27種とする本もありますが、本サイトで確認できた一次資料（Plant Pono）は23種です。hala（パンダナス）は NPS の植物ガイドが「ポリネシア人が持ち込んだ」と「在来」の両方に分類していて、人が運んだのか元からいたのか、公的資料でも決着していません。
</Note>

### kalo と Hāloa

Bishop Museum は「ハワイの伝承ではタロは人の兄であり、それゆえ非常に神聖な役割を持つ」と説明します。Pukui-Elbert の辞書は kalo の項で「ハワイでは最古の時代から今日まで主食で、栽培が大きく発達し、**300以上の品種**を含む」と記します。人と kalo の兄弟関係は講座 Moʻolelo Lesson 01（Hāloa）で扱いました。

## 在来植物 — 人より前からいた層

- **<H>ʻōhiʻa</H> lehua**（Metrosideros polymorpha）— 湿潤から中程度の降水量の森で優占種。若い溶岩流に最初に定着する木の一つで、海面から2,200m以上まで育ちます。約390万年前にニュージーランド起源の祖先が渡来。在来林の約80%を占め、州全体で約865,000エーカーに広がります
- **<H>koa</H>**（Acacia koa）— 大木になり、カヌーの材に使われた。若木は複葉、成木は葉柄が平たく広がった「仮葉」になる二形が特徴
- **<H>māmane</H>**（Sophora chrysophylla）— Mauna Kea 上部に残る絶滅危惧種の鳥 palila のほぼ唯一の餌。palila の密度は māmane が多い場所ほど高い
- **<H>ʻiliahi</H>**（白檀）— 19世紀初頭の交易で乱伐された

<Photo id="koa-phyllode" caption="koa の枝。複葉（右）から仮葉（左）へ移行する途中の葉が同じ枝に出ている。" />

<Note kind="unverified">
koa のカヌー材としての利用の詳細と、ʻiliahi 交易の年代（1790〜1825年など諸説）は、本サイトの調査では DLNR・USDA Forest Service の一次資料に到達できず、確認できていません。
</Note>

州の花は **<H>maʻo hau hele</H>**（Hibiscus brackenridgei、黄色いハイビスカス）。1988年に州議会が正式に定めました。Maui・Lānaʻi・ハワイ島の標高120〜730mに自生する固有種で、絶滅危惧種です。

## フラの植物 — 身につける層

フラで使う植物の中心は、講座 Moʻolelo Lesson 04 で見た Laka の <H>kuahu</H> の標準5種——**lehua・maile・hala pepe・ʻieʻie・palapalai**——です。それに加えて次のものが lei や衣装に使われます。

| 植物 | 使いどころ |
|---|---|
| <H>ʻaʻaliʻi</H>（Dodonaea viscosa） | 赤い莢を染料に、実と葉を lei に。「風に倒れない」の ʻōlelo noʻeau で知られる |
| <H>kī</H> / <H>lāʻī</H> | pāʻū（スカート）、lei、供物の包み |
| <H>hala</H> | lauhala の編み物、実の lei |
| <H>kukui</H> | 実の lei。「光」の kaona |
| <H>ʻilima</H> | Oʻahu の島花。薄い花びらを何百枚も重ねた lei |

<Note kind="hula">
maile・palapalai・lehua と Laka の結びつきについては、Emerson（1909）が祭壇に許される植物として列挙していることが根拠です（Moʻolelo Lesson 04）。「この植物は Laka の kinolau だから使う」と言うとき、その出典が Emerson なのか、自分の hālau の伝承なのかを分けて持っておくと、人に説明するときに強くなります。
</Note>

## Rapid ʻŌhiʻa Death — 摘む前に知っておくこと

2010年、ハワイ島 Puna で ʻōhiʻa が急速に立ち枯れる現象が見つかりました。2018年、原因菌が新種2種と判明し、University of Hawaiʻi がハワイ語の種小名を与えました。

- **Ceratocystis lukuohia**（「ʻōhiʻa の破壊者」）— 数週間で枯らす強毒種
- **Ceratocystis huliohia**（「ʻōhiʻa の状態を変える」）— 数か月から数年かけて枯らす弱毒種

2018年7月時点でハワイ島の推定40,469ha に広がり、Kauaʻi（2018年12月確認）・Maui・Oʻahu でも見つかっています。Oʻahu では弱毒種のみ16本にとどまります。

<Photo id="rod-station" caption="Hilo 空港の ROD 検疫・消毒ステーション（2018年）。ʻōhiʻa の花・葉・枝・材はハワイ島から持ち出せない。" />

NPS と Oʻahu Invasive Species Committee が勧める行動:

1. 決められたトレイルから外れない
2. 森に入る前後に靴を70%イソプロピルアルコールか10%漂白剤溶液で消毒する
3. 道具と衣類をお湯と石鹸で洗う
4. ʻōhiʻa の花・葉・枝・材をハワイ島の外へ持ち出さない
5. 車のタイヤと車体の下を洗う

<Note kind="caution" title="lehua を摘む前に">
NPS が紹介する伝承では、嫉妬した Pele が若者 ʻŌhiʻa を木に、恋人 Lehua をその花に変え、花を摘むと二人が引き離されるため雨が降る、と語られます。ROD の時代、lehua の lei を作るなら、**どこの木から、どう採るか**が以前より重い問いになりました。採取前の oli や pule の作法を明文化した一次資料は本サイトでは確認できていません。自分の hālau の作法に従ってください。
</Note>
