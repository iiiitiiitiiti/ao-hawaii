<Lead><H>mele</H> は詩の総称、<H>oli</H> は踊りを伴わない詠唱。mele inoa、mele maʻi、mele kanikau、mele pana……種類の名は歌の「用途」を表します。歌の骨組み（kaʻi・paukū・haʻina・hoʻi）と、oli の声の様式、そして <H>kaona</H> を辞書の定義から読み直します。</Lead>

## mele と oli

- <H>mele</H> — 「あらゆる種類の歌・讃歌・詠唱。詩。歌う、唱える」（Pukui-Elbert）
- <H>oli</H> — 「踊りを伴わない詠唱。特に、長い句を一息で唱えるもの」（同）。定義そのものに「一息で」という様式が含まれています

Emerson（1909、第40章）は mele と oli の境界を、形式ではなく**歌い手の気分**（mood）に置きました。「oli と、inoa・kanikau・pule といった重い形の mele との境界は、ほとんど歌い手の気分の中にある」。oli の語源は olioli（喜ばしい）で、「喜び、したがって歌の観念を伝える」と説明しています。

## mele の種類 — 用途で分ける

| 種類 | 何の歌か | 出典で確かめられること |
|---|---|---|
| <H>mele inoa</H> | 名前の歌。人を讃える | Emerson 用語集「a name-song; a eulogy」 |
| <H>mele maʻi</H> | 生殖器を讃える歌 | 辞書「首長の誕生時に作られ、大人のためにはまず作られない。たいてい陽気で速い」。Kaʻiwakīloumoku は「初子の誕生時に血統の存続を祝い励ますため」と説明 |
| <H>mele kanikau</H> | 哀悼の歌 | ʻuwē helu（数え上げる泣き歌）を含む |
| mele hoʻoipoipo | 恋の歌 | hoʻoipoipo＝求愛する |
| mele koʻihonua | 系譜・創世の歌 | Kumulipo が代表（講座 Moʻolelo Lesson 01） |
| <H>mele pana</H> | 土地の歌 | 例: Kauaʻi の72行の oli「Maikaʻi nā Kuahiwi」 |
| mele kāhea | hālau に入る合言葉 | Emerson「a password by which one gained admission to the halau」 |
| mele aloha | 愛の歌 | Emerson が「E Piʻi i ka Nāhele」をこう分類（Hūlili 経由） |

<Note kind="unverified">
mele hula・mele oli・mele lei・mele hoʻāla・mele komo は、辞書に複合語としての独立項目がありません。構成語の組み合わせとして理解されている語です。
</Note>

## oli の声の様式

Emerson が用語集と本文で区別している様式:

| 様式 | 特徴 |
|---|---|
| <H>hoʻāeae</H> | 「静かで感傷的な朗唱。iʻi（声の震え）があっても目立たせない」。恋歌に |
| <H>olioli</H> | hoʻāeae と対比。「より温かく、iʻi の変動を極端にする」 |
| kāwele / koʻihonua | 「はっきりした自然な声で唱える」。koʻihonua は ʻai haʻa の「気取った大げさな調子」と対比される |
| ʻai haʻa | 「力んだ喉声」。威圧・力の誇示に |
| <H>kepakepa</H> | 現代の解説では「祈りに用いる速くリズミカルな朗唱」。ただし Emerson の kepakepa は「隠語的な言い回し」を指す語で、指す範囲が違う可能性あり |

iʻi は「声の特別な震え、揺れ」（Ke Ola Magazine）。hoʻouwēuwē（哀悼調）などの名は、本サイトの調査では辞書・Emerson のどちらからも様式の解説を確認できていません。

## mele の骨組み

| 語 | 定義（Pukui-Elbert） |
|---|---|
| <H>kaʻi</H> | 「観客の前に踊りながら出てくること。踊り手が現れ、去る間の詠唱」。入場と退場の両方に使われうる |
| <H>paukū</H> | 「節、部分、スタンザ」 |
| <H>haʻina</H> | 「歌の最後の2節（時にそれ以上）。たいてい haʻina の語で始まり、主題または捧げる相手の名を繰り返す」 |
| <H>puana</H> | 「歌の始まり、主音。要約の refrain」 |
| <H>hoʻi</H> | 「踊り手が観客の前を去るときに踊る、別れの詠唱」 |

**Haʻina ʻia mai ana ka puana** — 直訳は「その要約（puana）が語られる」に近く、慣用では「歌の主題はここに語られた」という結びの定型句。直後に曲名か、捧げる相手の名を置きます。

> Haʻina ʻia mai ana ka puana
> ʻO Haliʻalaulani kou inoa

（「Hanohano Pihanakalani」。要約は語られた／あなたの名は Haliʻalaulani）

> Haʻina ka puana
> I ka ua Kanilehua

（「Hilo Hanakahi」。この歌の締めくくりは／Kanilehua の雨について）

## kaona — 定義に戻る

Pukui-Elbert は <H>kaona</H> を「ハワイの詩歌における隠された意味。人・物・場所への隠された言及。幸運または不運をもたらしうる二重の意味を持つことば」と定義します。同じ項に **kaona hoʻoʻinoʻino**（悪意を込めた当てこすり）もあり、kaona は肯定的とは限りません。

<Note kind="caution" title="「kaona＝性的な隠語」ではない">
定義は「人・物・場所への隠された言及」一般で、性的な含意に限定されていません。すべての mele に性的な kaona を読むのは、定義の射程を超えた過剰一般化です。
</Note>

辞書に載っている比喩義から、kaona の実例を四つ:

1. **lehua** — 「戦士、愛する友や親族、恋人、達人」（PE）。Andrews 1865「高く尊ばれる人を指して比喩的に使われることが多い」
2. **<H>pua</H>**（花）— 「子孫、子ら」。用例「pua aliʻi＝首長の子孫」。**Kaulana Nā Pua**（名高き花々）の「花」がハワイの人々を指すのは、この語義による
3. **makani**（風）— 「比喩で、怒り、噂」。用例「Mai walaʻau aʻe hoʻi o makani auaneʻi＝しゃべりすぎるな、風が吹く（噂になる）ぞ」
4. **ua**（雨）— 各地に固有の名を持ち、場所と結びついた象徴として働く。辞書は「雨は大地を潤すゆえに愛され、kāhiko o ke akua（神の装い）と呼ばれた」と記す

実践の例として、**Hole Waimea** の huapala.org の解題は「pua o koaiʻe（koaiʻe の花）」を「delicate parts の婉曲表現」と明記し、「この古い詠唱の一部は double entendre つまり kaona に満ちている」と述べます。hole 自体が「手荒に扱う／情熱的に愛撫する」の両義です。

## 代表的な mele — 作者と背景

| 曲 | 作者・年 | 背景 |
|---|---|---|
| **Kaulana Nā Pua**（Mele ʻAi Pōhaku、Mele Aloha ʻĀina） | Ellen Kehoʻohiwaokalani Wright Prendergast、1893年1月作、1895年出版 | Royal Hawaiian Band の楽団員が「併合への抗議を曲に」と依頼。講座 Mōʻaukala Lesson 04 |
| **Aloha ʻOe** | Liliʻuokalani。huapala は1878年作曲とする | Maunawili 訪問の帰路、Pali を越える間に仕上げたとの逸話（Lahilahi Webb らの回想）。作曲年と逸話の細部は諸説あり |
| **Hilo Hanakahi** | Keola Naumu。King's Songs of Hawaiʻi（1938） | Hanakahi は Hilo の古い首長の名、Kanilehua はその地の雨の名 |
| **Hole Waimea** | 伝承、作者不詳 | ハワイ島 Waimea の槍の走者集団 Kīpuʻupuʻu の物語。Kamehameha I の mele inoa で Liholiho に受け継がれた |
| **Kāwika** | J. Kealoha。King's Hawaiian Melodies（1930） | Kalākaua への mele inoa。英仏に財政支援を求めて断られた逸話を歌い込む |
| **Nā Aliʻi** | Samuel Kuahiwi。同上 | Order of Kamehameha に献呈。Māmalahoe Kānāwai と1843年の Kamehameha III の言葉を織り込む |
