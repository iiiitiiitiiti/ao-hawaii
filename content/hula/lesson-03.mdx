## 基本ステップ — 辞書の定義で読む

Pukui-Elbert『Hawaiian Dictionary』（1986）が定義しているステップと、その原文の要約です。

| ステップ | 辞書（Pukui-Elbert 1986）の定義 |
|---|---|
| <H>kāholo</H> | 4カウントで一方の足を横へ出し、他方を引き寄せる。左右で繰り返す。語義は「素早い、敏捷な」「長い針目で縫う」。huapala（PE 引用）は「現代の踊りに多い haʻa の vamp ステップ」と補う |
| <H>hela</H> | 片足を前と横の中間、約45度に置き、体重は反対側の腰、その膝は曲げる。足を戻し、もう一方で繰り返す |
| <H>ʻuwehe</H> | 片足を上げ、下ろしながら体重を反対の腰へ移す。踵を素早く上げて両膝を前へ押し出し、腰は左右に揺れ続ける。「難しいステップ」と辞書自身が書く。ʻuehe・ʻuweke の綴りも登録されている |
| <H>ʻami</H> | 腰を回すステップ。下位分類として ʻami kāhela（＝ʻami poepoe）、ʻami kūkū、ʻami ʻōniu、ʻami kuʻupau、ʻami ʻōpū を明記 |
| <H>lele</H> | 前へ歩き、一歩ごとに後ろの踵を上げ、わずかに内へ。ʻuwehe を伴うことも。後ろ向きにもできる |

huapala.org が Pukui-Elbert から引く定義（辞書本文では直接確認できていないもの）:

- **ʻami kūkū** — ʻami kāhela と同じだが回転が小さく速く、3回1組。kūkū の語義は「小刻みに揺れる」「瓢箪を当て布に3回打ちつけ、3回目に叩く打ち方」
- **ʻami ʻōniu** — 腰の回転が横8の字を描き、体重移動を伴う。ʻōniu は「独楽」
- **lele ʻuwehe** — ʻuwehe と lele の複合
- **<H>kāwelu</H>** — 片足の踵で拍を取り、もう一方の足を前後に踏む。**huapala は「Kalākaua」と同一項目に載せる**。同じ動きに二つの名がある直接の証拠
- **<H>kiʻi wāwae</H>**（huapala の見出しは「kiʻi（wāewae kīʻi）」）— 右足を横・前・後ろの順に置き、左足で繰り返す
- **<H>ʻai haʻa</H>** — 膝を曲げて行うステップ
- **ʻai kāwele** — 片足が床に触れずに前から横へ半円を描く haʻa ステップ。「ʻai kaʻa」に近い名で辞書側はこれを採る。綴り差・呼称差の可能性あり

<Note kind="caution" title="辞書に無い教室の語">
<H>kaʻo</H>（左右に揺れる）は、辞書には「乾いた、不毛の」しか載っておらず、huapala も「origin unknown」として辞書外の教室用語に分類しています。<H>lewa</H> は「空、浮かぶ、揺れる」の一般語で、関節の柔らかい踊り手を形容する用法はありますが、技法名としての独立項目はありません。**教室で通じる語と辞書にある語は別**——どちらが正しいという話ではなく、出どころが違います。
</Note>

## ʻami — Emerson の定義と弁護

Emerson（1909）は hula kuʻi の章で、ʻami を「**骨盤と体幹の中心軸を円か楕円の軌道で振る動きを、極端にしたもの**」と定義しています。「腰を回す」とは書いていない。中心軸の動きとして記述している点は、体の使い方を考えるときに役立ちます。

同じ Emerson は脚注で、フラへの「猥褻」批判の中心が ʻami にあったことを認めた上で、こう書きました。

> But the ami did not necessarily nor always represent obscenity, and to this extent the hula has been unjustly maligned.

巻末索引には「AMI, not a motion of lewd intent」の項が立っています。**1909年の時点で ʻami の弁護が必要だった**——その事実が、禁止期の批判の焦点を物語っています。

## 教室で使う語

| 語 | 辞書の語義 | 教室での使い方 |
|---|---|---|
| <H>hoʻomākaukau</H> | 準備する | 「用意」の号令。号令としての用法は辞書に無い |
| <H>ʻae</H> | はい、同意する | 応答 |
| kuʻu | 放す、緩める、（詠唱を）終える、閉会する | 「下ろす・緩める」の指示に転用 |
| <H>kāhea</H> | 呼ぶ。**踊り手が次の節（paukū）の冒頭を唱えて詠唱者に合図すること**、と辞書が明記 | — |
| hoʻokahi | 一つ、だけ | カウントの起点 |

<Note kind="point" title="kāhea には二つの意味がある">
辞書の kāhea は「踊り手が次の節の冒頭句を唱えて hoʻopaʻa に合図する」こと。一方 Emerson（p.38）の **mele kāhea** は「hālau に入る許可を請う合言葉の詠唱」（mele wehe puka とも）で、巻末用語集も「a password by which one gained admission to the halau」と定義します。同じ語が二つの場面で使われている。実践者でも混同しやすい点です。
</Note>

## ʻūniki — 辞書と Emerson のずれ

Pukui-Elbert の <H>ʻūniki</H> は「graduation exercises（卒業の儀式）」。Emerson の用語集は「the début or the first public performance of a hula actor（初舞台）」。**卒業と初舞台**——二つの定義は完全には重なりません。ʻūniki の中身は Lesson 05 で扱います。
