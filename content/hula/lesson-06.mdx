## Merrie Monarch — 公式の歴史

| 年 | 出来事（公式「History of the Festival」） |
|---|---|
| 1963 | 津波被害と Hāmākua のサトウキビ産業の衰退で苦しむハワイ島で、County の Chairwoman **Helene Hale** が観光振興として構想。Gene Wilhelm と George Naʻope を Maui の Lahaina Whaling Spree へ視察に送る |
| 1964 | 第1回。**Kalākaua そっくりのヒゲ・コンテスト、バーバーショップ・カルテット、リレー、戴冠式の再現、Holokū Ball**。当初はフラ競技ではなかった |
| 1968 | 関心が落ち込み中止寸前。**Dottie Thompson** が自ら Executive Director を引き受けて存続 |
| 1971 | Thompson と Naʻope がフラ競技を導入。助言は Pauline Kekahuna・Louise Kaleiki・ʻIolani Luahine・Lokalia Montgomery・Puanani Alama。wahine 部門に9 hālau、初代 Miss Hula は Aloha Wong（のちの Dalire） |
| 1976 | kāne 部門を開設。初代優勝は Nā Kamalei O Līlīlehua（Robert Cazimero） |
| 1978 | Hoʻolulu Tennis Stadium（現 Edith Kanakaʻole Multi-Purpose Stadium）へ移転 |
| 1980 | 三夜制に。初めてチケットが完売 |
| 1981 | テレビ中継開始。Lunalilo Home の kūpuna が見られるように、という Thompson の思いが動機と娘 Luana Kawelu が語る |
| 2010 | Aunty Dottie 死去。娘 **Luana Kawelu** が President を継承 |
| 2020 | 中止（公式の歴代優勝一覧に「Cancelled」と明記） |

公式の「Past Winners」PDF（1971〜2021）を見ると、初期の部門名は今と違います。1971年は「Implements Div. / Modern Div. / Overall」、1972年は「Ancient / Modern / Implements」。**楽器を用いる Implements 部門が独立していた時期があり、kahiko／ʻauana の2部門制は最初からではない**。また1971〜75年の優勝は「Hauʻoli Hula Studio」「Johnny Lum Ho Hula Studio」など「Studio」名が並び、**「hālau」と名乗るのが一般化したのは後年**と読み取れます。

## Merrie Monarch のほかに

- **Kūpuna Hula Festival**（Kona）— <H>kūpuna</H>（年長者）部門の大会。2025年は9月10〜11日
- **Ka ʻAha Hula O Hālauaola**（世界フラ会議）— 数年ごとに開かれ、hālau が競わずに学び合う場。2018年は Hilo で開会式
- **King Kamehameha Hula Competition**（Honolulu、1974年創設とされる）— 本サイトの調査では公式サイト・報道に到達できず、近年の結果は未確認。日本版（駒沢オリンピック公園）は3部門の優勝 hālau が Honolulu 大会の出場権を得る、と日本語版 Wikipedia にある（未検証）

<Note kind="hula" title="ʻōhiʻa の島間移動制限">
Merrie Monarch の時期に合わせて毎年、Rapid ʻŌhiʻa Death 対策のため ʻōhiʻa の島間移動が制限されているという注意喚起が出ます（2025年・2026年とも報道あり）。**lei や kuahu の材料として ʻōhiʻa lehua を島をまたいで持ち出せない**。実践者に直結する現行のルールです（講座 Nā Mea Ola Lesson 03）。
</Note>

## Nā Hōkū Hanohano — 審査制の2部門

Hawaiʻi Academy of Recording Arts（HARA）の音楽賞。公式サイトによれば起点は**1978年、KCCN-AM ラジオ**（当時世界唯一の全編ハワイアン音楽局）で、DJ の Krash Kealoha（Victor ʻŌpiopio）が発案。第1回は一般投票で、業界団体が投票する現在の形になったのは1982年です（「HARA 設立1982年」は正しいが「賞の開始1982年」は誤り）。

選出は有料会員のオンライン投票で、Board of Governors は受賞者を決めません。ただし **<H>haku mele</H>（作詞作曲）と Hawaiian Language Performance の2部門は審査員制**で、ハワイ語と音楽の専門家の委員会が選びます。フラの実践者にとって、この2部門だけ選出方式が違う点は覚えておく価値があります。

2025年・2026年の Hawaiian Album of the Year と Haku Mele の受賞者は、本サイトの調査では公式サイト上で一覧を確認できませんでした。
</Note>

## ハワイ語復興との結びつき

| 年 | 出来事 |
|---|---|
| 1896 | Republic of Hawaii の Act 57 で公私立学校の教授言語が英語のみに。ハワイ語の使用が事実上禁止 |
| 1978 | 州憲法（第15条4節）でハワイ語が英語と並ぶ公用語に |
| 1983 | ʻAha Pūnana Leo 設立（Larry Kimura、Kauanoe Kamanā、Pila Wilson ら）。1984年に Kauaʻi の Kekaha に最初の Pūnana Leo（当初は違法状態） |
| 1987 | 州教育委員会の決定（1986年）で、学校でのハワイ語教授が再び認められる |

話者数は推計がまちまちで、ネイティブ話者約300人（2006年）、第二言語話者2万2千〜2万4千人、家庭内使用1万8千人（2016年州推計）。UNESCO は「危機的絶滅危惧」に分類しています（いずれも Wikipedia 経由、要裏取り）。Merrie Monarch の Hawaiian Language Award が Miss Aloha Hula と重なり続けていることは、フラが言語復興の現場でもあることの表れです（講座 Mōʻaukala Lesson 05、ʻŌlelo Hawaiʻi Lesson 01）。

## 敬意と商業化 — 論点の整理

本サイトの調査では、kumu hula の団体の声明や、商業化・「hula girl」の表象・映画への反応についての一次資料・報道に到達できませんでした。ここでは**論点だけ**を、これまでの講座で確かめた事実に結びつけて置きます。

- **表象の歴史** — 1927年の映画『Hula』、1937〜2002年の Kodak Hula Show、hapa haole の歌（Lesson 01）。観光が作った「hula girl」像は、Kaʻahumanu の布告と王国の許可制が「ハワイ人女性が人前で踊ること」を統制した歴史（同）の裏返しでもある
- **系譜と資格** — kumu hula の正統性は「誰から学び、ʻūniki を経たか」に置かれる（Lesson 05）。系譜のない「kumu」を名乗ることへの批判は、この構造から出てくる
- **言語** — Hawaiian Language Award が示すとおり、mele をハワイ語として理解して踊るかどうかが評価の軸にある。歌詞の意味を知らずに踊ることへの批判はここに根がある
- **土地** — lei の材料をどこから採るか（ROD、島間移動制限）、Halemaʻumaʻu への hoʻokupu の作法（講座 Moʻolelo Lesson 03）。敬意は抽象論ではなく、植物と土地の扱いに現れる

<Note kind="unverified">
「文化盗用」をめぐる具体的な声明・事件・映画（2024年『Moana 2』、2025年実写『Lilo & Stitch』）への反応は、本サイトでは確認できていません。これらを引くときは、必ず一次資料に当たってからにしてください。
</Note>
