# 014. 確認問題の選択肢は、表示するときに問題文から決まる順へ並べ替える

- 日付: 2026-09-24
- 対象: `src/widgets/Quiz.tsx`（`choiceOrder`）、`tests/quiz.test.ts`、全レッスンの `<Quiz>`

## 決定

本文（MDX）の `choices` と `answer` は書いた順のまま置き、`Quiz` が表示するときに問題文のハッシュから決まる順へ並べ替える。同じ問題はいつ開いても同じ順になる。テストで「表示上の正解の位置が一か所に4割以上集まらない」ことを検査する。

## 背景

2026-09-24 に数えると、108問のうち69問（64%）で正解が2番目にあり、4番目は1問だけだった。書き手が「正解を2番目に置く」癖を持っていて、位置で当ててしまえる。並べ替えたあとの分布は 31・33・23・21 問。

## 比較した代替案

| 案 | 却下理由 |
|---|---|
| 108問の choices と answer を手で並べ直す | 書き手の癖は次の問題でも出る。新しい問題を足すたびに偏りが戻る |
| 開くたびに乱数で並べ替える | 「最初から見直す」で同じ問題の選択肢の位置が変わり、見直しにくい。テストで分布を検査できない |
| 並べ替えず、テストで偏りを検査するだけにする | 既存の108問を直す手間は案1と同じで、書くたびにテストに落とされる |

選択肢の文言に「上のすべて」「どれも違う」のような位置に依存するものは無いことを確かめた（2026-09-24）。足すときは避ける。

## 影響範囲

- 本文の `why` に「2番目の選択肢」のような位置の言及を書かない
- `answer` は書いた順の添字のままでよい

## 検証

`tests/quiz.test.ts`（全問を取り出し、並べ替えが置換であること・毎回同じ順であること・位置の偏りが4割未満であること）。ブラウザで Moʻolelo 02 の問題を解き、正解の色付けが並べ替えのあとも正しいことを確かめた。
