# 007. 「未確認」注記をやめ、言い切るか出典を名指しする

- 日付: 2026-09-18
- 対象: `content/**/*.mdx`、`content/pages/notation.mdx`、`tests/hedging.test.ts`、`docs/DESIGN.md`（004 の運用を一部改める）

## 決定

本文で「○○に記述がないため怪しい」「本サイトの調査では確認できていません」と書かない。事実の書き方は出典の数で決める。

| 出典の数 | 書き方 |
|---|---|
| 2つ以上 | 本サイトの判断でまとめて言い切る。細部が食い違うなら「A は○、B は△」と並べ、本サイトが採る値を示す |
| 1つ | その出典を本文で名指しする（「Kent 1993 の集計では」「Wikipedia「Kaʻahumanu」による」） |
| 0 | 書かない。「要確認」ラベルにも置き換えない |

`<Note kind="unverified">` は本文から全廃し、`tests/hedging.test.ts` が禁止フレーズ（本サイトの調査では／記述がな／裏取り／未確認／未検証／可能性あり／断定は避け／諸説あり／確認できていません）を検査する。

## 背景

サイトの持ち主（読者本人）の指示。「マニュアルがわかりにくくなるので、複数の情報があればまとめて言い切ってしまってよい。1つしか情報がない場合はその情報を引用してください」。公開時点の本文には unverified ノート27件と、インラインの「要裏取り」「未確認」が約50か所あり、読み手に判断を丸投げしていた。

## 比較した代替案

| 案 | 却下理由 |
|---|---|
| 【要確認】ラベルへ統一（文体憲法第10条の形） | 読者が持ち主本人なので「確認するのは自分」になり、注記は宿題の山になる。持ち主が「言い切ってよい」と判断した以上、ラベルも不要 |
| unverified ノートを残し、文言だけ柔らかくする | 「怪しい」という情報自体を残すことになり、指示の趣旨に反する |
| 出典0の主張を残して出典欄に「なし」と書く | 出典を示せない事実は事実として書かない（文体憲法第11条）。削るのが一貫する |

## 影響

- 削った主張は `docs/verification-2026-09-18.md` 末尾の「未確認のまま」から消え、レッスンにも残らない。再掲したいときは一次資料を見つけてから書く
- 持ち主が所有する紙の資料（Pukui-Elbert 辞書 1986、Place Names of Hawaii、He Mele Aloha）で裏が取れた項目は、今後 H1/H2 の形で本文へ戻せる
