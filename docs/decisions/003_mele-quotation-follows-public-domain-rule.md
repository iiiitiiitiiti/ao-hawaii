# 003. 歌詞（mele）の全文掲載は日米両国で保護期間が満了したものに限る

- 日付: 2026-09-18
- 対象: `docs/DESIGN.md`「歌詞（mele）引用の規約」、各レッスンの引用

## 決定

instrument-lessons DDR 004（作詞者全員が1967年末までに死亡、かつ1929年より前に出版）をテキストにも適用する。それ以外の mele は解説に必要な1〜2行の引用に留め、作者名・曲名を添える。引用した mele は `<Sources>` に掲載元を書く。

## 背景

設計レビュー（Opus）で「画像だけ厳格で、mele 引用は野放し」と指摘された。Kaulana Nā Pua（1893）、Kūnihi ka mauna（Emerson 1909 収録）、クムリポ冒頭（Kalākaua 版 1889）は全文可の側、Hilo Hanakahi（Keola Naumu、1938 出版）などは引用の側になる。

## 比較した代替案

| 案 | 却下理由 |
|---|---|
| 歌詞は一切載せない | 文法講座と kaona の説明が例文なしでは成り立たない |
| 引用は無制限（教育目的） | 日本の著作権法32条の「必要最小限」を超えると説明できない |

## 検証

本文中で全文または節単位で引用したのは、クムリポ冒頭11行（1889）、Kaulana Nā Pua の連の抜粋、Kūnihi ka mauna の冒頭2行、Emerson 収録の pule（1909）。いずれも1929年以前の出版で作者は1967年以前に死亡（Prendergast は1902年没）。
