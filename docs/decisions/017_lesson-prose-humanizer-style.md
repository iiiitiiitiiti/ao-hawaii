## 017. 本文の見出しと箇条は「A — B」を使わず、和欧文の半角空白は残す

- 日付: 2026-10-20
- 対象: `content/**/*.mdx`、`content/mele/*.ts` の日本語の地の文

### 決定

本文の見出しは `## A — B` をやめ、短い1つの名詞句にする（例: `## 北西ほど古い島`）。括弧で終わる形とコロンでつなぐ形も使わない。箇条の `**ラベル** — 説明` は `**ラベル**: 説明` にする。ラベルが評価や述語なら1文にする。ハワイ語・英語の前後の半角空白は残す。

### 背景

全講座の本文を humanizer-ja（AI らしい日本語を直すスキル）に通した。スキルの既定は全角ダッシュも和欧文の半角空白も直す側だが、このリポジトリは半角空白で全体が統一されている。どこまでスキルに従うかを先に決める必要があった。

### 比較した代替案

| 案 | 却下理由 |
|---|---|
| 見出しのダッシュを残す | 見出しが「主題 — 結論」の2つの主張を持ち、目次で長くなる。外した結論は本文の最初の文に置けば足りる |
| `## A（B）` の形にする | 括弧で終わる見出しは補足を見出しに詰めているだけで、長さが変わらない |
| 和欧文の半角空白を外す | 全ページで統一された表記を崩す。ʻokina・kahakō 付きの語は前後が詰まると読みにくい |
| 箇条のラベルを全部外して文にする | 用語集・年表・段階の箇条はラベルが見出しの役を持つ。外すと拾い読みできない |

### 影響範囲

- 新しいレッスンを書くときの見出しと箇条の書き方
- 残すダッシュは、Sources の label・note、引用の中、表の空欄、`src/content/courses.ts` の講座題とレッスン題
- 見出しの id は `src/lesson/LessonToc.tsx` が連番で振るので、見出しの文言を変えても目次のリンクは変わらない
- 誤解の訂正を担う否定対比（「〜ではなく〜」）は残す。Quiz の `choices` と `answer` は書き換えない

### 検証

2026-10-20 に全56ファイルを書き換え、`npm run lint`・`npm test`（544件）・`npm run build` が通った。本文に ` — ` が残っていないことを grep で確かめた。見出しから外した結論が本文に無い節が見つかったら、この判断の運用が崩れている。
