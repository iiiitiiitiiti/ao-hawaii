# 005. カタカナの発音近似と音声は入れない

- 日付: 2026-09-18
- 対象: 講座 ʻŌlelo Hawaiʻi Lesson 01、`docs/DESIGN.md` Non-goals

## 決定

ハワイ語の発音はカタカナで書かない。音節分割・強勢の規則・w の条件（PE 辞書の "usually"）で示す。音声も入れない。

## 比較した代替案

| 案 | 却下理由 |
|---|---|
| カタカナ併記 | 読者はフラ歴18年で歌詞を読める。w の [v] や二重母音を誤って固定する害のほうが大きい（設計レビューの指摘） |
| ハワイ語 TTS や録音 | 信頼できる自由ライセンスの音源が揃わない。合成音声は ʻokina と長母音を正しく出せない |

## 検証

Lesson 01 に「カタカナ近似は使わない」旨を書き、pau / paʻu / paʻū / pāʻū の対と強勢規則で代替した。
